# Rapid Key Tapper

Experience seamless key tapping with Rapid Key Tapper, a lightweight Windows utility designed to auto-tap or auto-repeat any keyboard key effortlessly.

## Features
- Utilizes the SendInput hardware scan-code API for reliable key event delivery.
- Compatible with fullscreen games and Remote Desktop Protocol (RDP) sessions.
- Simple and intuitive interface for quick setup and customization.
- Light on system resources, ensuring smooth performance without lag.
- Ships as a compact MSI installer, making installation straightforward.
- Open source under the MIT license, allowing for community contributions and transparency.
- No ads or telemetry, ensuring a clean user experience.
- Works seamlessly with any keyboard layout.
- Supports rapid key press functionality for efficient gaming and productivity.

## How to use
1. Download the Rapid Key Tapper MSI installer.
2. Install the application on your Windows 10 or 11 system.
3. Launch Rapid Key Tapper and select the key you wish to auto-tap.
4. Configure the tap rate and any other desired settings.
5. Activate the key tapper to begin auto-tapping your selected key.
